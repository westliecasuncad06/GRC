# Quick Reference: PDF Download Feature

## Where to Find PDF Download

### 1. **Top Navbar** (Most Prominent)
```
[Download Complete PDF] button - White button with PDF icon
```
- Always visible at the top of the page
- Click to download complete manual
- Mobile: Shows PDF icon only

### 2. **Welcome Screen** (Central Location)
```
Orange/Yellow notice box with:
- PDF icon
- Description
- [Download Complete PDF] button
```
- Appears on the home/welcome screen
- Highly visible with orange theme
- Explains what's included in the PDF

### 3. **Sidebar Quick Links** (Alternative Access)
```
Footer icons: [PDF] [Print] [Fullscreen] [Home]
```
- PDF icon (first icon)
- Always accessible from any manual page
- Tooltip: "Download Complete PDF"

## What Gets Downloaded
- **Filename**: `GRC_Complete_User_Manual.pdf`
- **Contents**: Complete user manual with all three roles:
  - Administrator Manual
  - Professor Manual  
  - Student Manual
- **Source**: `/manuals/USER MANUAL.pdf`

## Other Actions

### Print Current Manual
- **Navbar**: "Print" button (secondary style, white border)
- **Sidebar**: Print icon in quick links
- **Keyboard**: Ctrl+P / Cmd+P

### Navigation
- **Sidebar**: Click manual cards on welcome screen
- **Left Menu**: Select Administrator, Professor, or Student
- **Keyboard**: Ctrl+K / Cmd+K for search

## Design Features
- **Colors**: Orange/amber theme for PDF downloads (stands out)
- **Icons**: Font Awesome icons (fa-file-pdf, fa-download)
- **Responsive**: Adapts to mobile, tablet, and desktop
- **Animations**: Smooth fade-in and hover effects
